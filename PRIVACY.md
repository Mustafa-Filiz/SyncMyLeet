# Privacy Policy – Sync My Leet

**Last updated: November 20, 2026**

Sync My Leet is a Chrome extension that helps users synchronize their accepted LeetCode solutions with their own GitHub repositories.

## 1. Information We Access

Sync My Leet accesses the following information:

- **LeetCode submission data:** Problem title, submission ID, programming language, difficulty, source code, submission status, runtime, memory usage, and related metadata.
- **GitHub credentials:** A GitHub Personal Access Token provided by the user to authorize repository access.
- **Extension settings:** GitHub repository owner, repository name, synchronization preferences, and submission history.

## 2. How We Use Information

The information is used exclusively to provide the extension's functionality:

- Retrieve accepted LeetCode submissions.
- Upload solution files to the user's selected GitHub repository.
- Generate and update a README file containing solution statistics.
- Store submission history and synchronization status.
- Authenticate requests to GitHub on behalf of the user.

## 3. Data Storage and Sharing

GitHub credentials, settings, and submission history are stored locally using Chrome Storage.

Submission data is transmitted to GitHub only when required to perform the synchronization requested by the user.

Sync My Leet does not operate its own backend server and does not transmit user data to analytics, advertising, tracking, or other third-party services.

## 4. Data Security

GitHub Personal Access Tokens are stored locally in Chrome Storage and are used to authenticate GitHub API requests.

Users are encouraged to create a fine-grained GitHub Personal Access Token with access limited to their selected repository and the minimum required permissions.

## 5. Data Retention and Deletion

Users can remove their GitHub connection through the extension settings.

Uninstalling the extension removes its locally stored extension data according to Chrome's storage behavior. Files previously synchronized to GitHub remain in the user's repository until the user deletes them.

## 6. Third-Party Services

The extension interacts with:

- **LeetCode:** To retrieve submission information.
- **GitHub:** To upload and manage solution files.

These services are governed by their own privacy policies and terms.

## 7. Changes to This Policy

This privacy policy may be updated when the extension's functionality or data practices change.
